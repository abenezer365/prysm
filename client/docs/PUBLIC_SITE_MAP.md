# Public Site Map

The canonical registry is `src/config/publicRegistry.js`. It currently represents more than 50 meaningful destinations across six discovery groups.

- Research: hub, ethical AI, responsible AI, fraud detection, AML, behavioral intelligence, transaction analytics, network intelligence, graph/GNN research, model evaluation, explainability, provenance, human oversight, security and trust.
- Intelligence: overview, models, data representation, graph, GNN, methodology, safe playground, investigations reference.
- Academy: hub, data science, Python, machine learning, financial intelligence, AML fundamentals, resources, opportunities, institutions, regulations.
- Resources: documentation hub, architecture, API, frontend, backend, data, integration, security, authentication, authorization, investigations, graph, RAG, chat, models, errors, developer guide, glossary, FAQ.
- Organization: About, story, mission, team, Abyssinia Associates, acknowledgements, contributors, beta, contact, request access.
- Reports and policies: reports hub, bug report, resolution guide, system status, release notes, security, responsible disclosure, privacy, terms.

Routes are reflected in both mega-navigation and the larger footer map. `public/sitemap.xml` contains the primary index routes and should be generated from the registry when a deployment base URL is known.
